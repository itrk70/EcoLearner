## Purpose

The testing directory documents all quality assurance activities performed during the development of EcoLearner.

Testing reports help:
- Identify bugs
- Verify bug fixes
- Improve user experience
- Ensure responsive design
- Prepare the project for demonstration

Every major prototype update should include a new testing report.
